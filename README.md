# AutomaticHunting Global

由 WayneXXDD 維護的國際服繁體中文版本，從 SFY 的 AutomaticHunting 2.4.5.0 DLL 還原並移植。原作者署名與來源記錄保留於 [NOTICE.md](NOTICE.md) 和 [analysis](analysis/)。

## 安裝

在 Dalamud 加入插件庫：

`https://raw.githubusercontent.com/WayneXXDD/DalamudPlugins/main/pluginmaster.json`

開啟 **Get plugin testing builds（取得測試版插件）**，刷新清單後搜尋 **AutomaticHunting Global**。目前版本為 **2.5.0.2**，使用國際服 Dalamud API 15；仍需遊戲內實測。

需要 **vnavmesh** 導航，以及 **Lifestream** 跨服與切換分流。使用 `/auht` 顯示狀態浮窗，`/auht setup` 開啟設定精靈，`/auht stop` 停止導航。

## 插件總開關

小浮窗（含精簡模式）與設定視窗標題列均有 **啟動插件／關閉插件** 按鈕，摺疊設定視窗後也能操作。狀態顯示 **已關閉**，或開啟後的 **已開啟・待命／導航中**。

- 每次載入插件及登出後都預設關閉；舊設定中的啟用狀態也不會自動恢復。車頭、坐騎、位置與其他設定保留。
- 啟動後才會監聽車頭及執行跟車。完成首次設定也會先保持關閉。
- 關閉會取消導航、連車、血量監控及等待中的標點、切線和傳送重試；由本插件啟動且仍在執行的 Lifestream 工作也會停止。已經進入遊戲過圖的傳送無法撤回。
- 重新開啟只接受新的工作，不會恢復關閉前的舊標點或延遲動作。
- 指令 `/auht on`、`/auht off` 使用相同總開關；`/auht stop` 仍只停止本次導航。

## 自動傳送開關

在「跟車設定 → 導航與戰鬥 → 自動傳送」切換，預設開啟以保留既有行為。

- 開啟：選擇適合的水晶傳送，再飛向車頭的地圖標點。
- 關閉：不主動傳送；同張地圖仍自動飛向標點。不同地圖時保留最新標點，等待自行或接受隊伍傳送抵達後再導航。
- 等待期間的新座標會取代舊座標；停止導航或關閉總開關會取消等待。
- 關閉時略過自動切線及其水晶傳送重試；手動跨服與傳送工具仍可使用。

## A 怪搜尋半徑

在「跟車設定 → 導航與戰鬥 → A 怪搜尋半徑」調整，預設 200 公尺，範圍為 50～500 公尺；以角色為中心計算水平距離。接近標點到設定距離內即開始搜尋，每 0.5 秒檢查一次。

未找到 A 怪時繼續靠近標點，到 10 公尺內會停下並最多再搜尋 5 秒。只能搜尋遊戲已載入到角色附近的怪物；加大數值不會增加遊戲載入距離，也不會自動繞圈找怪。

## 隊伍傳送後重新尋路

導航途中接受隊伍傳送或發生過圖時，先停止舊導航並清除舊路點，等待尚未完成的舊尋路結束。角色、地圖與導航準備完成並穩定一秒後，從傳送落地位置重新規劃到保留的目的地，不會重新啟動自動傳送。

若已找到 A 怪，會保留其目的地位置；手動前往標點也會恢復。被傳到目的地以外的地圖時會等待，新的標點或手動目的地會取代舊等待；停止導航、關閉總開關或卸載插件會取消恢復。

## 繁體中文顯示

- 設定介面、提示、狀態與內嵌說明統一為繁體中文。
- 地圖、怪物與坐騎清單加入繁體中文譯文；顯示翻譯不會改動遊戲辨識、傳送目的地或儲存的原始名稱。
- 人物、伺服器、資料中心及相依插件的名稱保留原名，方便與遊戲和安裝清單對照。指令保持可直接執行的格式。
- 隨插件附上 Noto 繁體中文字型，並在編譯時檢查內建文字的字元涵蓋情況。

遊戲內容譯文根據 [中文遊戲資料](https://github.com/thewakingsands/ffxiv-datamining-cn) 轉為繁體中文，可能與其他繁體中文版本的官方譯名不同。

程式位於 [src](src/)，編譯與發布由 GitHub Actions 處理。原版已停用的跨服車頭功能維持停用；戰鬥輸出由玩家或其他插件負責。
